# 💰 Millionfund - 基金估值查询系统

一个功能完整的基金投资分析工具，提供基金估值查询、涨跌预测和支撑位/压力位自动计算功能。

## ✨ 核心功能

### 📊 基金查询
- 🔍 支持基金代码和名称搜索
- 💾 本地收藏功能（自动保存到本地存储）
- ⭐ 快速查询常用基金

### 📈 数据分析
- **涨跌分析**：日/周/月/年涨跌幅实时显示
- **趋势预测**：基于历史数据的智能趋势判断
  - 短期/中期/长期趋势预测
  - 目标价位计算
- **支撑位/压力位**：自动计算三个级别
  - 强支撑/压力位（52周最低/最高）
  - 中支撑/压力位（20%跌幅处）
  - 弱支撑/压力位（10%跌幅处）
- **风险评估**：基金风险等级和波动率分析

### 💡 智能功能
- 📱 完全响应式设计，支持各设备
- 💾 本地存储持久化
- 🎨 美观的数据可视化界面

## 📊 使用示例

```
1. 输入基金代码（如：000001）或名称
```

## 🧮 计算算法

### 支撑位/压力位计算
```javascript
const range = high52w - low52w;

// 压力位
强压力 = 52周最高价
中压力 = 当前价 + (范围 × 25%)
弱压力 = 当前价 + (范围 × 10%)

// 支撑位
强支撑 = 52周最低价
中支撑 = 当前价 - (范围 × 25%)
弱支撑 = 当前价 - (范围 × 10%)
```

### 趋势预测
基于以下因素综合判断：
- 短期涨跌幅（1周）
- 中期涨跌幅（1月）
- 长期涨跌幅（1年）
- 目标价位 = 当前价 × (1 + 年涨跌幅% + 5%)

### 风险评分
```
低风险基金:   3/10
中风险基金:   5/10
中高风险基金: 7/10
高风险基金:   9/10
```
